# iris-brush

Brush engine, dynamics, stabilizers, stroke buffer.

- Package: `org.appthere.iris.brush`
- Convention plugin: `iris.kmp.library`
- May depend on: `iris-core`, `iris-pixels`, `iris-color`, `iris-input` (`docs/architecture.md` §1; checked by `ArchitectureTest` from A4)
- Engine module: no Compose and no platform API (`android.*`, `java.awt.*`, `platform.UIKit.*`, Skia and others). Plain Kotlin in `commonMain`.
