# iris-editor

`EditorSession`, tools, history, selection ops, transforms.

- Package: `org.appthere.iris.editor`
- Convention plugin: `iris.kmp.library`
- May depend on: `iris-model`, `iris-render`, `iris-brush`, `iris-input`, `iris-io` (`docs/architecture.md` §1; checked by `ArchitectureTest` from A4)
- Engine module: no Compose and no platform API (`android.*`, `java.awt.*`, `platform.UIKit.*`, Skia and others). Plain Kotlin in `commonMain`.
