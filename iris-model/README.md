# iris-model

Document, layers, effects, selections, `Command`, `Change`.

- Package: `org.appthere.iris.model`
- Convention plugin: `iris.kmp.library`
- May depend on: `iris-core`, `iris-pixels`, `iris-color`, `iris-vector` (`docs/architecture.md` §1; checked by `ArchitectureTest` from A4)
- Engine module: no Compose and no platform API (`android.*`, `java.awt.*`, `platform.UIKit.*`, Skia and others). Plain Kotlin in `commonMain`.
